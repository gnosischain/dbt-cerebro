int_governance_gip

The GIP spine — one row per GIP number, unifying forum discussion (topics/posts/views/phase flags) with Snapshot proposal(s). Canonical `outcome` is set only when unambiguous (single decisive result across ballots); conflicting decisive outcomes set outcome NULL and outcome_ambiguous. Full ballot history stays on int_governance_proposals.
