api_hopr_channel_activity_daily

Daily payment-channel activity per network, SPLIT BY is_cover_traffic. The split is the contract: on dufour nearly every event is HOPR paying its own node runners in proportion to stake, so a total across the split presents a rewards schedule as user demand. Consumers must split or filter. tickets_redeemed is the trustworthy volume measure; channels_opened is not comparable across years. Ends at the complete previous day (dashboard convention); the current day's rows exist upstream in fct_hopr_network_daily.
