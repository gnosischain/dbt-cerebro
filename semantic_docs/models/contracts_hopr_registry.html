contracts_hopr_registry

Address / ABI / network resolution point for every HOPR model. THREE HOPR environments run on Gnosis Chain simultaneously - dufour (legacy production, hoprd v2/v3), jura (v4, the network the GnosisVPN client defaults to) and rotsee (the v4 testnet, flagged is_testnet). dufour emits the same logical events under different topic0s than the v4 pair, so ABIs must resolve per contract address. Both v4 environments were REDEPLOYED once at block ~4741xxxx (2026-07-27), so a network maps to more than one address per contract_type and both generations are listed - dropping the legacy generation truncates history at the redeploy date. Only the current jura addresses own event_signatures rows; every other row points abi_source_address at them. Addresses come from hoprnet/contracts ethereum/bindings/contracts-addresses.json cross-checked against HOPR's own published contract registry; every start_blocktime is the contract's own creation date from execution.contracts.

Columns

NameTypeDescription
abi_source_addressStringAddress whose event_signatures rows carry this contract's ABI. For proxies this is the PROXY's own address, not the implementation: fetch_abi_to_csv.py stores the implementation's ABI under the proxy's contract_address, so signature_generator keys the rows on the proxy. Only point this at a different address when the ABI genuinely lives under another contract (shared runtime ABIs, Safe singletons).
addressStringContract address, lowercased with 0x prefix.
contract_typeStringLogical contract type, used as the decode_logs contract_type_filter.
discovery_sourceStringProvenance of the row, for example hoprnet_contracts_addresses_json.
is_dynamicUInt81 if the contract was discovered from a factory, 0 if statically declared. All HOPR rows are static.
is_testnetBoolTrue for rotsee. Derived here (prefix-safe) so the on-chain side carries the same testnet concept the blokli staging models expose, and production marts have one flag to filter on. rotsee tickets and balances are not real economics -- never aggregate them with dufour or jura.
networkLowCardinality(String)HOPR environment this deployment belongs to: dufour, jura, or the rotsee testnet. Not unique per contract_type -- each v4 environment has a legacy and a current deployment.
start_blocktimeStringContract creation date, taken from execution.contracts rather than estimated from a block delta.
