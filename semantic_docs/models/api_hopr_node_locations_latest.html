api_hopr_node_locations_latest

Current nodes aggregated to a plottable point: one row per (network, country, city) with coordinates. DELIBERATELY INCOMPLETE -- nodes without coordinates cannot be plotted and are excluded here, so a map built on this alone under-counts the network. Publish the 'UNKNOWN' residual from api_hopr_nodes_by_country_latest alongside any map. Coordinates are ipinfo city centroids, not machine locations: every node in a city collapses to one point, which is the honest resolution for IP geolocation.
