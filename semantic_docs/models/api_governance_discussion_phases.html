api_governance_discussion_phases

Discussion and endorsement per proposal per lifecycle phase: before the proposal existed, after it existed but before voting opened, during the vote, and after it closed. Rows exist for any (proposal, phase) with either posts or likes, so a phase where people only clicked like is still present -- an ABSENT row means nothing happened, a zero means the phase had activity of the other kind. Coverage is 137 of 253 proposals (54%), effectively all GIPs; filter is_gip = 1 for aggregates. CAUTION on cross-phase comparison: pre_discussion and post_close are UNBOUNDED windows while voting is typically 7 days, so comparing raw post counts across phases is not like-for-like. Compare per-proposal or per-day.
