fct_celo_gpay_settlement_batches

One row per settlement transaction - how many card charges it swept, how much left the contract, where it went, and what the bridge hop cost in CELO. Built on the decoded event layer contracts_celo_gpay_settlement_events. There is no settlement lag and no float, which is why this model exists instead of the lag and float marts originally scoped. The sweep is atomic - all 476 settlement transactions contain both the charges and the outflow, and not one does only one or the other. Charge-to-settlement time is therefore zero by construction and value in flight never exists. The only residual is cross-token - about 10 percent of (transaction, token) charge groups pull a token that transaction does not settle, so it waits for the next sweep of that token. Charge amounts are token-agnostic on purpose. The legacy contract reports the WRONG token on TokenPullSuccess - it labels all 1,752 of its pulls USDC while the chain shows 345 USDC and 1,407 USDT arriving. Counts and amounts are correct, only the token field lies. Both stablecoins are 6-decimal so the summed amount stays exact, but a per-token split of charges would not be and is not offered. Settlement outflows DO carry the right token on both contracts, verified against raw ERC-20 Transfer logs, which is why charges and settlements are sourced differently here.

Columns

NameTypeDescription
batch_dateDateCalendar date of the settlement transaction.
batch_timeDateTimeTimestamp of the settlement transaction.
bridged_amountFloat64Stablecoin units bridged off Celo in this transaction.
charged_amountFloat64Total pulled from cards, in stablecoin units. Token-agnostic - see the model description. Exact because both settlement stablecoins carry 6 decimals.
destination_eidsArray(String)LayerZero destination endpoint IDs for bridged value. 30101 (Ethereum) is the only value observed. Empty for transaction that only settle locally.
failed_amountFloat64Amount GP attempted to pull and could not (originAmount on the failure event).
fee_usd_per_chargeNullable(Float64)Bridge cost attributed per card charge in the batch. NULL rather than 0 when a batch has no charges, so empty batches drop out of averages instead of dragging them toward zero.
n_bridgedUInt64SettlementBridged events - value sent to another chain via LayerZero.
n_chargesUInt64Successful card charges (TokenPullSuccess) swept in this transaction.
n_failed_chargesUInt64Failed pulls (TokenPullFailedWithAmount) in this transaction. 7 in total ever, all between 2026-05-28 and 2026-06-29, none since.
n_transferredUInt64SettlementTransferred events - value sent to a receiver on Celo.
native_fee_celoFloat64CELO paid for the LayerZero hop. Zero for locally-settled batches, which cost nothing beyond gas.
native_fee_usdFloat64native_fee_celo priced at the batch date.
receiversArray(String)Distinct settlement receivers in this transaction. An array because one transaction can bridge one token and locally transfer another to different destinations. The local receiver changed from 0x8ab54f9e to 0xdc9b73c3 after 2026-06-10.
settled_amountFloat64Total stablecoin units that left the contract. Equals charged_amount per contract over all time.
settled_usdFloat64settled_amount priced per token at the batch date.
settlement_contractStringAddress of the settlement contract, unprefixed lowercase as stored in the decode layer.
settlement_labelStringsettlement_legacy or settlement_current, from the celo_gpay_settlement_contracts seed. 'unknown' would mean a contract is emitting settlement events without being in the seed, which should never happen.
transaction_hashStringThe settlement transaction. One row per hash.
transferred_amountFloat64Stablecoin units transferred to a Celo receiver in this transaction.
