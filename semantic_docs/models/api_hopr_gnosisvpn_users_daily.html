api_hopr_gnosisvpn_users_daily

Served GnosisVPN client activity per network per day -- the demand side. Exposes BOTH user definitions: active_users_* (HOPR-comparable; redemption OR first key-binding) and using_users_* (redemptions only). They are not interchangeable and the difference between them is the deployed-but-never-used cohort, so a chart captioned "GnosisVPN users" must say which one it plots. The 30d window is 31 days inclusive and the 7d window is 7, an asymmetry inherited from HOPR's own query for comparability. No bandwidth column exists: tickets are probabilistic payments, not bytes. Passthrough of fct_hopr_gnosisvpn_users_daily. Ends at the complete previous day (dashboard convention); the current day's row exists upstream in the fct.
