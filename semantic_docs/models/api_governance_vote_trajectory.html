api_governance_vote_trajectory

How opinion FORMED across a voting window: one row per (proposal, hour since voting opened) with cumulative against-share by headcount and by voting power. Viable because the median proposal spreads 100 votes over 50 distinct active hours in a 168h window. Intended use is to overlay forum post timestamps and find where the against-share inflects -- a COINCIDENCE DETECTOR, not a causal claim; label any UI "posts near an inflection", never "posts that caused". Both curves are exposed because a jump in voting power without a jump in headcount means one whale moved. Hours with no votes are absent, not zero -- do not read a gap as flat support. Filter on proposal_total_votes before drawing.
