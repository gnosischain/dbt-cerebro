fct_celo_gpay_balances_safe_daily

DENSE per-Safe/token/day net-flow balance (Celo analog of Gnosis Chain's int_execution_gpay_balances_user_daily). Densified over a date spine so downstream daily totals and latest-day snapshots are correct on every day. Net flow = (Top-up + Reversal) - (Payment + Withdrawal). Equals the true on-chain balance only for whitelisted tokens under the documented scope assumptions (see file header). Not a chain-wide balance snapshot.

Columns

NameTypeDescription
balanceFloat64Cumulative net NATIVE-token balance as of this date. This is the quantity of tokens held; 25,676.93 across all cards on 2026-08-04.
balance_usdNullable(Float64)MARK-TO-MARKET USD value: `balance` valued at the token's price as of this date, carried forward from the last observed price via ASOF join. It is NOT a running sum of each flow's USD value — that would be an accumulated cost basis, a different quantity that goes arbitrarily wrong for a volatile token (and can go negative while the card still holds it). Flows are valued at transaction time (int_celo_gpay_activity.amount_usd, correctly historical); stocks are valued as of the reporting date, which is this column. NULL, never 0, when a held token has no price at or before this date — unknown must not read as empty. sum() therefore skips such positions, which is what the two valuation tests on this model guard against. Additive across cards and tokens within a date; NEVER across dates.
dateDateCalendar date (dense).
price_dateNullable(Date)The date of the price actually used to value this row. Equals `date` when an oracle answer landed that day, and is EARLIER when the ASOF join carried the last observed price forward (the price hub does not forward-fill). Exposed so the valuation is auditable and so staleness is assertable — the carry-forward is uncapped by design. NULL means no price existed at or before `date`, in which case balance_usd is NULL too.
safe_addressStringGP card Safe address.
token_classStringSTABLECOIN or RWA, from celo_tokens_whitelist ('UNKNOWN' if a symbol is somehow absent from the seed). Exists so headline figures can separate spendable float from reward holdings without hardcoding a symbol list — fct_celo_gpay_snapshots reports STABLECOIN as TotalBalance and RWA as RewardBalance.
token_symbolStringUSDC or USDT.
