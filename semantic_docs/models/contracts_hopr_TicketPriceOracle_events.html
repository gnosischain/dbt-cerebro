contracts_hopr_TicketPriceOracle_events

TicketPriceUpdated, required to value redeemed tickets: ticket price is an oracle parameter and is not carried in the ticket event itself. Winning-ticket payout equals ticket price divided by winning probability - verified against observed payouts (dufour 10.0, jura 2.5 wxHOPR).
