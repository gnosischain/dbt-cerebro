stg_hopr_db__blokli_nodes

Per-node identity snapshot from blokli, HOPR's own v4 indexer, ingested by click-runner's hopr-blokli ingestor. Reads FINAL (ReplacingMergeTree(ingested_at)). JURA AND ROTSEE ONLY -- blokli does not serve dufour, the mirror image of the prober's coverage. rotsee is a testnet; filter on is_testnet before using any of it in a network metric. THIS IS A CROSS-CHECK, NOT AN INGESTION SOURCE. Measured against the on-chain jura node set, blokli returns no node int_hopr_nodes does not already have, disagrees on no IP, and would contribute a single additional address -- so int_hopr_nodes deliberately does not read it. Its value is that agreement: it independently confirms the Announcements decode, and it carries packet_key and keyid, which exist nowhere on-chain.

announced_ipNullable(String)IPv4 address parsed out of multiaddress. NULL for /ip6/ or /dns4/ addresses -- guarded on the /ip4/ prefix so a non-IPv4 address yields NULL rather than a fragment that would look like an address to ipinfo and silently fail to enrich.
is_testnetBoolTrue for rotsee (any rotsee-prefixed value). CAST strips LowCardinality before the comparison because comparing a LowCardinality(String) to a literal yields LowCardinality(UInt8), which ClickHouse Cloud rejects with code 455.
keyidUInt32blokli's own incrementing node id. Exists nowhere on-chain.
multiaddressStringAnnounced libp2p transport address, e.g. /ip4/185.9.1.97/udp/9091/quic-v1.
multiaddress_countUInt8How many addresses the node announced.
networkStringHOPR network the node belongs to, NORMALIZED to the bare name (jura or rotsee) so it joins the on-chain side, which uses bare names from contracts_hopr_registry_static. blokli decorates the name on some feeds ('jura-prod'); the mapping is prefix-based and applied once here, never in a consumer. See raw_network for what the API actually returned.
node_addressStringOn-chain node address, lowercase 0x-prefixed. blokli calls this chain_key; renamed here to match every other HOPR model.
packet_keyStringThe node's packet (offchain) key, used for mixnet routing. Not recoverable from chain data -- blokli is the only source.
raw_networkStringThe network name exactly as blokli returned it, before normalization. This feed serves bare names today, so it usually equals network; it exists so a newly decorated value is visible rather than silently folded away.
safe_addressStringAddress of the node's staking Safe.
snapshot_dateDateDate of the blokli snapshot.
