int_rpc_state_indexer_token_balances_daily

Daily holder balances per token, read from the rpc-state-indexer census (balanceOf at the day's verified anchor block) instead of accumulated from Transfer logs. Scoped to the tokens_whitelist seed, which supplies symbol, token_class and decimals. Census-derived successor to int_execution_tokens_balances_native_daily; every day stands alone, so there is no carry-forward and no seed day.
