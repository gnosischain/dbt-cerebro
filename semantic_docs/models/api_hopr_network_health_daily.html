api_hopr_network_health_daily

Daily nodes-ever-registered versus nodes-actually-online per network. The two are not interchangeable: registration is cumulative and never expires, so the registry figure runs several times the live network and the gap has widened every year. Never label either "network size" without saying which. Read nodes_online_avg with hours_observed -- the upstream hourly history has real gaps. NULL prober columns mean unmeasured, never zero; prober coverage is dufour-only.
