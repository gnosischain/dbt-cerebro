int_quarterly_esg_carbon_intensity_with_fallback

Monthly carbon intensity per country for the quarterly ESG reports: the months Ember has published, read from int_esg_carbon_intensity_ensemble. Until 2026-11 it forward-filled each country's last known month for up to 11 months (flagged is_estimated); the ESG chain now waits for Ember's publication instead, so the flag was dropped. The name stays because the semantic layer reads this view.
