hopr_db.hopr_network_online_hourly

Hourly count of online HOPR nodes from the network.hoprnet.org dashboard's own history. Backfilled in one call (the API returns the whole series), so it needs no daily run and carries history from 2023-09 that no other feed has. The series is NOT gap-free -- roughly a fifth of expected hours are absent -- so consumers must count observed hours rather than assume 24 per day.
