hopr_db.hopr_blokli_network_snapshot

Daily network-level snapshot from blokli: live protocol parameters (ticket price, minimum winning probability, key binding fee, closure grace period) plus account/safe/channel counts and balances. The only source of jura economics and staked balances that needs no balance indexing. Forward-only -- no history before the ingestor first ran.
