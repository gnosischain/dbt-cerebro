int_quarterly_esg_carbon_footprint_with_fallback

Daily annualised CO2 and energy for the quarterly ESG reports, read from fct_esg_carbon_footprint_uncertainty, which ends on the last day of the latest month for which Ember has published the World carbon intensity. Until 2026-11 it extended the fact table with estimates built from forward-filled carbon intensity (flagged is_estimated); it now waits for Ember's publication, so the flag was dropped.
