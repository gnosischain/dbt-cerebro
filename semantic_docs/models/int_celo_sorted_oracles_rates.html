int_celo_sorted_oracles_rates

Tracked Mento SortedOracles rate feeds on Celo, raw-sliced from celo_execution.logs (MedianUpdated events, values at Mento's 24-decimal fixidity). Currently a single feed: the relayed CELO/XAUt rate (CGP-0240 / MGP-17, daily heartbeat at 00:00 UTC since 2026-06-09) — the only native on-chain gold price surface on Celo, since no direct Chainlink XAU aggregator exists there (verified on-chain). Consumed by int_celo_token_prices_daily to derive XAUt/USD.
