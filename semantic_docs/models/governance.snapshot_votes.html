governance.snapshot_votes

Raw votes as returned by the Snapshot API, one row per (proposal, vote id). A voter re-voting on an open proposal can produce a new vote id, so raw may hold >1 row per voter — stg_governance__snapshot_votes dedupes to the latest vote per (proposal_id, voter).
