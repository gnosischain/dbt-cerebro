crawlers_data.ember_generation_monthly

Ember monthly electricity data ("generation" release, wide format): one row per Area x month x Electricity source, metrics as columns. The click-runner ember-ingestor reloads the whole file on the 8th and 21st into a ReplacingMergeTree(ingested_at); read it with FINAL. Replaced ember_electricity_data, whose long-format file Ember retired on 2026-11-02 (that table stays frozen at data to 2026-06).
