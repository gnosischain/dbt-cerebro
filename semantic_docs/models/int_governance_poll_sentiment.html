int_governance_poll_sentiment

One row per (post, poll): a forum poll collapsed into a for/against tally, with the timing of the post hosting it. The only record of one-person-one-vote community sentiment on questions that later get a token-weighted Snapshot vote -- the missing middle of the discussion -> signal -> vote funnel. TIMING COMES FROM THE HOST POST: the poll row has no created_at (close_at is a schedule, ingested_at is first-seen), so it is dated by its host post via an INNER JOIN on post_id -- coverage verified 184 of 184. An undated poll must not silently acquire a phase downstream. poll_against_share is NULL rather than 0 when nothing decisive was cast or any count was withheld; a hidden live poll reading as 0% opposition would be worse than no number.
