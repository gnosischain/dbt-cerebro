api_hopr_nodes_hosting_latest

Current node counts per network per hosting provider, with the host-concentration figures. 'Unknown' means the org string matched no rule in the shared ipinfo classifier -- it is NOT residential and must not be folded into either side of a home-vs-datacenter split. 'NO_IPV4' and 'UNRESOLVED' are published for the same reason. nodes / distinct_hosts is the honest concentration read.
