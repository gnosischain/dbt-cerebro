api_hopr_protocol_params_daily

Daily protocol parameters and staked/locked wxHOPR from blokli, HOPR's own v4 indexer. JURA ONLY -- blokli has no dufour endpoint, and rotsee is filtered out as a testnet. payout_per_winning_ticket_wxhopr is the figure worth showing: HOPR pays probabilistically, so ticket price alone means nothing and is not comparable across networks running different winning probabilities. FORWARD-ONLY -- history starts when the click-runner ingestor first ran and earlier days cannot be recovered.
