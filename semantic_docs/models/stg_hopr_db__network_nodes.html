stg_hopr_db__network_nodes

Daily per-node quality snapshot from the network.hoprnet.org prober, ingested by click-runner's hopr-network ingestor. Reads FINAL (ReplacingMergeTree(ingested_at); re-running a day re-inserts it). DUFOUR ONLY -- the prober was never ported to jura/v4, so there is no liveness or latency signal for the network GnosisVPN runs on. Absence of a jura row means unmeasured, never down. node_address is already in the lowercase 0x form used by the decoded HoprChannels events, so it joins with no normalisation.

Columns

NameTypeDescription
availability_1yNullable(Float64)Fraction of the last year the node was up. The API currently returns NULL for EVERY node, so this is carried for shape only -- a consumer that filters or averages on it silently loses its whole population.
availability_24hNullable(Float64)Fraction of the last 24 hours the node was up, in [0,1].
availability_30dNullable(Float64)Fraction of the last 30 days the node was up, in [0,1].
availability_6mNullable(Float64)Fraction of the last 6 months the node was up, in [0,1].
availability_7dNullable(Float64)Fraction of the last 7 days the node was up, in [0,1].
first_seenNullable(DateTime)When the prober first observed this node.
is_reachableBoolWhether the prober reached the node, derived from latency_ms being non-NULL. Deliberately not derived from availability, which stays populated for a node that is currently down.
last_seenNullable(DateTime)When the prober last observed this node.
latency_msNullable(Float64)Averaged round-trip time the prober measured, in milliseconds. Fractional by nature -- the prober returns half-millisecond values, so this is a Float and rounding it to an integer discards real precision. NULL means the prober could not reach the node at all, which is the reachability signal rather than a gap.
networkStringNetwork name derived from the dashboard env id; dufour in practice.
node_addressStringOn-chain node address, lowercase 0x-prefixed. Joins directly to int_hopr_nodes.node_address and to HoprChannels source_node/destination_node.
prober_last_runNullable(DateTime)When the prober itself last ran, independent of this node's result.
snapshot_dateDateDate the prober snapshot was taken.
