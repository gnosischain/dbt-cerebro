int_governance_current_delegations

Current delegation state per (delegator, chain_id): their latest DelegateRegistry event ordered by (block_number, log_index) -- not block_time, which ties within the same block/tx (e.g. clear-then-reset in one transaction). Only currently-active delegations have a row here; a (delegator, chain) whose latest event is 'clear' has none. Grain is per chain because Snapshot reads both registries.
