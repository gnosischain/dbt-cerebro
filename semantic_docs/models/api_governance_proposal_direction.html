api_governance_proposal_direction

Per-proposal voting direction measured twice -- once by headcount, once by voting power -- plus the gap between them. Powers the "whales versus everyone else" view. Shares are over DECISIVE votes (for + against), excluding abstain so an abstain-heavy ballot never reads as consensus; abstain is exposed separately. Only choice_kind='single' (96.8% of proposals) is directional -- ranked-choice rows appear with NULL shares and directional = 0. Filter voters >= 30 before ranking (a divergence over a handful of voters is noise) and is_gip = 1 for any aggregate (119 of 253 proposals are non-GIP spam).
