int_governance_proposals

One enriched row per Snapshot proposal: derived outcome (passed/rejected/below_quorum/open), quorum_met, keyword category, winning choice, and vote aggregates (unique_voters, total_vp). Vote aggregates are pre-grouped then LEFT JOINed so no-vote proposals get 0, not an epoch.

Module: governance

Status: candidate

Owner: analytics_team

Path: models/governance/intermediate/int_governance_proposals.sql

Tags: production governance proposals

Columns

NameTypeDescription
categoryStringKeyword-derived category (Treasury & Funding, Technical & Protocol, ...).
idStringSnapshot proposal id.
outcomeStringpassed | rejected | no_consensus (abstain won) | decided (a selection ballot resolved -- the real result is winning_choice, e.g. GIP-148 -> "Noctua (Noca)") | below_quorum | open. Derived from the winning choice + quorum + finality; winning_choice always carries the actual winner.
unique_votersUInt64Distinct voters (deduped one-per-voter upstream).
winning_choiceStringThe choice label with the most voting power (any ballot type). Empty if no scores.
