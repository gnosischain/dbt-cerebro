int_celo_gpay_funder_wallets

The card <-> funding-wallet identity spine: one row per EOA that has directly funded a GP card Safe. WHY IT EXISTS: on Celo the Safe owner is useless as identity. GP's provisioning flow disables owner-based signing, so int_celo_gpay_safe_current_owners returns the dead sentinel 0x..02 for every card, and the funder equals the owner in ZERO cases (verified 2026-08-10 across all 1,015 solo-funded cards). The funding EOA is the only on-chain link between a card and the person behind it. SCOPE is direct EOA funders (is_direct_eoa_transfer = 1). Contract-mediated funders are Safes/routers, not people's wallets, and are excluded rather than flagged. Hubs are kept but flagged - filter is_solo_funder for user behaviour. NOT AN IDENTITY LABEL. "The wallet that funded this card" is the whole claim. It is NOT a MiniPay tag: there is no MiniPay marker on Celo and CIP-64 is a chain-wide fee envelope (models/celo/AGENTS.md).
