celo_execution.transactions

Signed transactions included in Celo blocks. transaction_type 123 (0x7b, CIP-64) is Celo's fee-currency envelope — the signer pays gas in an allowlisted ERC-20 (via a feeCurrency adapter for USDT/USDC) instead of CELO. It is necessary for MiniPay-style fee abstraction but NOT a MiniPay identity: a large share of all Celo activity uses type 123 (about two thirds of txs in 2026-07). For GP card funding, combine it with call shape and funder fan-out — see int_celo_gpay_funding_tx_envelopes.funding_channel. Type 126 (0x7e) is the OP-stack deposit/system transaction. feeCurrency itself is not stored in this table.
