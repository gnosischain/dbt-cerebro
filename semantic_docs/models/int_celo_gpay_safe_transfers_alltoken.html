int_celo_gpay_safe_transfers_alltoken

Deterministic all-token ERC-20 Transfer activity touching a GP card Safe on either side (int_celo_gpay_safe_registry) — NO token whitelist, NO counterparty labeling. Base for the deterministic Tier-1 enrichment (all-token balances, funding-relationship) AND the base that int_celo_gpay_activity classifies (whitelisted subset). `amount`/`amount_usd` are set only for whitelisted tokens (celo_tokens_whitelist, address-gated, so spoof tokens are excluded); `amount_raw` is always the exact integer. A Safe-to-Safe transfer yields two rows (one per Safe-side) by design. Incremental (insert_overwrite); the backfill is complete, so plain daily incremental is the correct path. Scans all Celo Transfer logs filtered to registry Safes — heavy on full-refresh (rebuild via scripts/full_refresh/refresh.py in monthly batches, never a plain --full-refresh), bounded per-month incrementally.
