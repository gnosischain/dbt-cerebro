contracts_celo_chainlink_feeds_events

Chainlink price-feed AnswerUpdated events on Celo (the 6 aggregators in seeds/celo_chainlink_feeds.csv), decoded from celo_execution.logs via the multichain decode pipeline (chain='celo'). Feeds int_celo_token_prices_daily. HEAVY: decodes AnswerUpdated across the full logs history, so it is full-refreshed in MONTHLY BATCHES by scripts/full_refresh/refresh.py (meta.full_refresh below; decode_logs honors the start_month/end_month vars the runner passes). A plain `dbt run --full-refresh` scans the whole logs table in a single query and OOMs (ClickHouse Code 241) — always rebuild via refresh.py.
