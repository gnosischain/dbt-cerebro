int_celo_gpay_safe_events_native

Safe lifecycle events (SafeSetup / AddedOwner / RemovedOwner) for GP card Safes on Celo, decoded through the multichain decode pipeline (chain='celo', ABI resolved from the Safe v1.3.0 L2 singleton row of the celo partition of event_signatures). SafeSetup rows are exploded one row per owner. Incremental append on monthly partitions, mirroring Gnosis Chain's int_execution_safes_owner_events: the output is bounded by card count, but a full rebuild re-scans celo_execution.logs across the whole GP era in one query and OOMs (CH code 241) now that the Celo backfill has landed. Rebuild through scripts/full_refresh/refresh.py in the monthly batches declared in meta.full_refresh below; decode_logs honors the start_month/end_month vars the runner passes.
