contracts_hopr_Channels_events

Decoded HoprChannels events for both live networks (dufour and jura). The ABI is resolved per contract address, which is what makes the dual-deployment decode correct: the two networks emit the same logical events under different topic0s, so a single-ABI decode would silently drop one of them. All 14 topic0s were verified against keccak of their canonical signatures. Neither network emits an amount - every balance-bearing event reports the NEW balance, so value requires a per-channel diff (see int_hopr_channels_events). HEAVY: ~3.0M rows decoded from the full execution.logs history since 2023-08-29.
