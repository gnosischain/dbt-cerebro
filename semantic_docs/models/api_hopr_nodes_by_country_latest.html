api_hopr_nodes_by_country_latest

Current node counts per network per country. Nodes with no resolvable IPv4 or no ipinfo row appear as country_code 'UNKNOWN' with geo_resolved = 0 -- they are a row, never a filter, because dropping them shrinks the denominator of every share a chart computes. live_nodes counts only prober-reached nodes and is 0 for jura because nothing measures it, not because jura is down.
