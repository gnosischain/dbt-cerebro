api_celo_gpay_wallet_tenure

How long GP card funding wallets had been active on Celo before funding a card, by tenure bucket. Read 'pre_dates_our_window' as "at least this long, unknown how much longer" - those wallets were already transacting when coverage opens at the L2 migration, so their true tenure is unmeasurable here and certainly longer than any number this model could print. See fct_celo_gpay_wallet_tenure.
