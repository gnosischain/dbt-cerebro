int_celo_token_prices_daily

Celo daily price hub, native-first (same design as the Gnosis int_execution_token_prices_daily). Priority 1: native on-chain — decoded Chainlink AnswerUpdated (CELO/USDT/USDC/USDm) and the derived XAUt/USD (Chainlink CELO/USD divided by SortedOracles CELO/XAUt). Priority 2: Dune off-chain feed fallback — load-bearing, not vestigial: the Celo Chainlink USDT/USDC aggregators only start 2026-06-23, so earlier stablecoin history resolves here or on the peg (XAUt0 before 2026-06-09 likewise). Priority 3: $1 peg last-resort for the card stablecoins. Daily price = last answer of the day. Forward-fill is NOT applied: a symbol is absent on a day with no oracle update, so downstream joins must tolerate a missing row rather than assume a dense date x symbol grid. Coverage as of 2026-08-03 is 496/496 days for CELO/USDC/USDT/USDm and 56/56 for XAUt0.
