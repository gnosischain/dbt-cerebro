hopr_db.hopr_network_nodes

Daily per-node quality snapshot from the dashboard prober (dufour only). node_address is the on-chain address and joins directly to decoded HoprChannels source/destination. latency_ms is NULL for nodes the prober cannot reach -- that is the reachability signal, not missing data. availability_1y is currently NULL for every node.
