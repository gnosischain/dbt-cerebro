api_execution_live_trades_minute_2h

Minute-grain DEX activity over the last 2 hours of cached live trades, stacked by protocol. Feeds a realtime "last 2h minute-by-minute" chart. `trade_count` is swap-event count (per hop); `volume_usd` sums per-hop conservative notionals (daily prices, same as the hourly chart). Anchored on `max(block_timestamp)` in `int_live__dex_trades_raw` with a 60-second reorg buffer. Minutes with no swaps for a protocol are absent (sparse).
