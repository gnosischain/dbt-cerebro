stg_crawlers_data__ipinfo

The stg_crawlers_data__ipinfo model aggregates and standardizes IP geolocation and organization data to support analytics on network infrastructure and traffic sources.

generic_providerStringNetwork type inferred from the ipinfo `org` string by pattern match: a named cloud/hoster bucket (AWS, Hetzner, ...), 'Hosting/CDN (Other)', 'Carrier/Transit', 'Public ISP (Home/Office)', or 'Unknown'. Classification is positive-evidence-only: an org that matches no rule yields 'Unknown', NOT a residential label. This matters because consumers turn the residential bucket into an economic claim -- int_esg_node_classification maps 'Public ISP (Home/Office)' to node_category='home_staker' at 0.80 confidence. Defaulting unrecognised orgs to residential, as this classifier once did, manufactured home-staker signal for every unmatched hoster: most of the residential bucket had matched no residential pattern at all, and the largest single block of it was a budget VPS provider. 'Unknown' scores 0.30 downstream, so an honest gap stays visible. Two consequences to respect when editing the classifier in stg_crawlers_data__ipinfo: - Do not add new top-level bucket names. ESG enumerates bucket names explicitly and falls through to node_category='unknown', so a new bucket would make a correctly-identified datacenter classify worse than an unrecognised one. Put additional hosters in 'Hosting/CDN (Other)', which ESG already reads as cloud_hosted. - `lowerUTF8` lowercases accents but ILIKE matches literal bytes, so accented brand spellings need care, and one stem is not enough: the accent sits in a different place per language, so 'telefonica' keeps "telef" while 'telefonos' breaks it at "tel-e". Match a stem on each side of the accent ('%telef%' plus '%fono%'). Missing one splits a single brand across buckets by country. Keep patterns ASCII -- some scripts/checks readers open model SQL without an explicit encoding. Coverage is deliberately incomplete rather than exhaustive: a small tail stays 'Unknown', mostly small regional ISPs and one-off hosters. Widen the pattern lists; do not narrow the fallback.

Use this to pick the latest per IP before joining on `ip`, otherwise the join fans out.
