fct_hopr_network_daily

Daily HOPR channel activity per network, split by is_cover_traffic. THE SPLIT IS THE POINT: on dufour, nearly every ChannelOpened event comes from the ten cover-traffic nodes HOPR publishes in ct-research -- the overwhelming majority in every year dufour has been live -- and the config's 48-hour channel max_age is what generates almost all observed churn. Cover traffic is HOPR paying node runners in proportion to stake -- a staking rewards programme -- so summing across the split would present a rewards schedule as user demand. jura carries no cover traffic.
