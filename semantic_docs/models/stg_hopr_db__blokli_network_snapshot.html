stg_hopr_db__blokli_network_snapshot

Daily network-level snapshot from blokli: live protocol parameters plus account, safe and channel counts and balances. Reads FINAL (ReplacingMergeTree(ingested_at)). JURA AND ROTSEE ONLY (no dufour). rotsee is a testnet whose ticket price and balances are orders of magnitude from production -- filter on is_testnet before summing anything. This is the only source of jura economics and of staked/locked balances that needs no balance indexing, and it is the live counterpart to the oracle events decoded from chain: ticket_price_wxhopr and min_ticket_winning_probability here should agree with the latest TicketPriceUpdated / WinProbUpdated. Disagreement means the decode is stale or an oracle address in contracts_hopr_registry is wrong. FORWARD-ONLY: blokli is queried for today, so there is no history before the ingestor first ran and none can be recovered. A gap in snapshot_date is permanent.
