int_governance_engagement_counters_daily

Daily snapshots of the two forum counters that CANNOT be recovered retroactively -- topic `views` and post `reads`. Discourse exposes both only as current totals with no per-event endpoint, and daily ingestion re-reads a topic only when its bumped_at beats the watermark, so a dormant thread's counters are frozen at its last activity. Likes are deliberately excluded: they have a per-event endpoint, so the full history including timestamps and actors is backfillable into forum_likes instead. THIS CANNOT BE BACKFILLED -- history starts the day it first runs. Partitioned by snapshot_date (NOT month): with insert_overwrite, a month-grain partition would wipe every earlier day in the current month on every run, since each run emits only today's rows.
