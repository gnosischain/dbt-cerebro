api_governance_delegates_latest

Delegate leaderboard: how many distinct gnosis.eth holders currently delegate to each address across both DelegateRegistry chains (1 and 100). A holder active on both chains counts once (uniqExact). See int_governance_current_delegations for how "current" is resolved. Delegation here is a separate on-chain relationship from the per-vote power-source split in int_governance_vote_power_source.
