api_governance_forum_topic_proposal_links

Forum discussion <-> Snapshot vote cross-links, topic grain. Unions two independent signals -- a pasted proposal/0x URL in a post (via_forum_post) and the proposal's own authored `discussion` field (via_discussion) -- so a link found by only one method still gets its own row (43 discussion-only rows verified; not merely a corroboration decoration on the post-link source). Includes topics where title-parsing found no GIP number but a linked proposal recovers the connection (recovered_via_link).
