stg_governance__snapshot_delegations

One row per DelegateRegistry event (chain_id, tx_hash, log_index) for the gnosis.eth space on Ethereum mainnet (chain 1) and Gnosis Chain (chain 100). Sourced from rpc_log_indexer.v_delegate_events_gnosis; SetDelegate/ClearDelegate remapped to set/clear. Use int_governance_current_delegations to resolve current state -- this is the raw event log.
