stg_governance__snapshot_proposals

One row per Snapshot proposal (latest version via FINAL), with GIP number parsed from the title and choices/scores arrays extracted from raw_json.

Columns

NameTypeDescription
choicesArray(String)Ballot choice labels, positionally aligned to `scores`.
discussionStringProposal-authored forum URL (Snapshot's own field). Empty for ~61% of proposals.
discussion_topic_idNullable(UInt32)Forum topic id parsed from `discussion`. NULL when discussion is empty, points elsewhere (another proposal, an unrelated domain), or has no numeric topic segment. Of 89 that parse, 43 have no corroborating pasted-post link at all -- a genuine additional coverage source, not just a corroboration signal (see api_governance_forum_topic_proposal_links, which unions both signals rather than treating one as primary).
gip_numberNullable(UInt32)GIP identity from a leading title match (parse_gip_number); NULL for non-GIP proposals and mid-title mentions.
idStringSnapshot proposal id (0x hash or older IPFS CID).
scoresArray(Float64)Per-choice voting-power totals, aligned to `choices`.
scores_stateStringpending | final (only 'final' scores are safe to report).
stateStringpending | active | closed.
