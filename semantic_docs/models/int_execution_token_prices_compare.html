int_execution_token_prices_compare

Side-by-side daily prices from native, hub, Dune, DefiLlama, and CoinGecko with pairwise absolute percentage diffs. Validation / QA only. After Phase 2a, hub already prefers high-confidence Llama over Dune at priority 3 — large hub-vs-Llama gaps on RWAs are expected (backedfi stays priority 2).
