crawlers_data.gp_migrated_safes

OLD -> NEW Safe mapping for the June 2026 post-exploit Gnosis Pay migration. One row per migrated Safe; a NEW Safe never appears as an OLD Safe, so a single hop resolves fully. Static dataset - the migration completed 2026-06-08 and no further rows are expected. Holds GnosisPay customer Safe addresses and is therefore SENSITIVE: it was previously a repo seed and must NOT be returned to one. This repo is public; the mapping is not derivable from public chain state (old and new Safes share no user-level owner by design, since the migration issued new signers), so publishing it would be a genuine disclosure rather than a convenience. See cerebro-mcp/docs/compliance/gdpr-audit-2026-07.md section 7.
