stg_governance__forum_polls

One row per (post, poll, option) with its vote count and a direction. option_votes = -1 (WITHHELD, because the poll's results policy hides counts) is mapped to NULL so a sum cannot read a hidden live temperature check as unanimous-nothing; genuine zeros survive as 0. Direction reuses classify_choice_polarity -- the same macro that labels Snapshot choices, so a poll's "In Favour" and a ballot's "For" mean the same thing. option_html is rendered HTML, so tags are stripped before matching. close_at stays Nullable and is a schedule, not evidence of closure.
