stg_rpc_state_indexer__token_balances_published

Cleanup view over the rpc-state-indexer published token balances — lowercases token and holder addresses, passes the published columns through. The same (token, date, holder) can appear under multiple job_names, so downstream consumers must filter chain_id + job_name or sums double-count.
